# Prenota Libro

1. Il lettore esegue il <u>login()</u> e richiede un nuovo prestito.
2. Il sistema carica le biblioteche registrate nel database degli utenti e le mostra al lettore.
3. Il lettore sceglie una biblioteca.
4. Il sistema esegue <u>importa metadati()</u>.
5. Il sistema crea una richiesta di prestito associando i metadati del libro, lo username del lettore e la salva nel database degli utenti.
